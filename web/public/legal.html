Privacy and legal

uploadmylaser · last updated 2026-09-26

What this is

uploadmylaser is an independent classroom project made by Dalton Fowler, a teacher, for his school district's classes. It is not a commercial product and has no accounts, ads or payments.

Safety

uploadmylaser is not a safety system. It limits laser power, speed and materials to the teacher's settings, and sends jobs to the laser. The limits it applies reduce mistakes; they do not make a job safe.

  • A trained adult checks every file and supervises the machine for the whole job.
  • Laser cutting can start fires. Never leave a running laser, and know where the emergency stop and the extinguisher are.
  • Only cut materials the teacher has approved. The site refuses some material names, such as PVC and vinyl, but a name check cannot know what a sheet really is.
  • Keep the lid closed and the fume extraction on while cutting.

The software is provided "as is", without warranty of any kind, as its open-source licence says.

Privacy

  • Your drawing, file or typed text is sent to the processing server only when you prepare a job. It is turned into laser instructions and not saved on the server.
  • The job goes from this browser straight to the laser over USB. It does not pass through the server.
  • The server keeps the class setup (materials, presets, machine settings) and the class phrase for the teacher.
  • No accounts, no cookies, no ads, no tracking. Cloudflare adds a Web Analytics script to the site; this site's security settings block it, so it collects nothing.
  • The site runs on Cloudflare. Like any web host, Cloudflare keeps short request logs (for example the page asked for, the time, the browser and the network address) for up to 7 days, to keep the site running. They are not used for anything else.
  • Your browser may keep your own settings and work (for example your theme, and your current work, a random id that keeps the processing server fair, and the class phrase for this tab) on this device only. Clearing site data removes them.
